# 知识星球网页全屏插件

## 功能说明
本Chrome插件专为知识星球网站(https://wx.zsxq.com/)设计，提供以下功能：
- 自动检测页面中的视频元素
- 为视频添加网页全屏控制按钮
- 一键切换整个网页全屏模式
- 保持页面原有布局和功能

## 安装步骤
1. 下载插件代码
2. 在Chrome浏览器地址栏输入：`chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本插件目录

## 使用说明
- 访问知识星球网站并打开包含视频的页面
- 插件会自动检测视频并放入全屏容器
- 点击右上角的"关闭全屏"按钮可退出全屏模式

## 技术特点
- 使用MutationObserver监听动态加载的视频
- 针对知识星球特定的视频元素结构优化(`video[_ngcontent]`)
- 等待视频加载完成后再进行处理
- 自定义全屏容器和关闭按钮

## 注意事项
- 需要Chrome 80或更高版本
- 仅适用于https://wx.zsxq.com/域名
- 如果网站更新DOM结构，可能需要更新插件
- 首次使用可能需要刷新页面
